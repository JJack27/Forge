Example chapter

This is the canonical chapter template. Every real chapter mirrors this structure exactly — the topbar, the inline BOOK_CONFIG, the chapter-header, objectives, body subsections, recap, pitfalls, and the test form. Copy this file, rename it, replace the content.

1.1 The main concept

Body prose goes here. Use <p> for paragraphs, <ul><li> for lists, <strong> for emphasis, <code> for inline code, and <pre><code> for code blocks. The dark-cyan theme styles all of these.

Subsection ids like sec-main-concept above are the anchors that test questions' data-review attribute links to. They are language-neutral: the same id appears in every language's copy of the chapter, so review links work no matter which language the learner is reading.

1.2 Inline SVG diagrams

Diagrams are pure inline SVG inside a <figure class="diagram">. No external images, no D3, no fetch. Use the theme colors: #38e0d6 (cyan), #6ee7ff (light cyan), #34d399 (green), #fbbf24 (amber), #f87171 (red), #a78bfa (purple), #aab0c0 (dim text), #e8eaf0 (text), #1d212c/#161922 (panel bg). Always set viewBox so the SVG scales; always include a <figcaption>.

1.3 Interactive demos

Demos are <div class="demo" data-demo="NAME"> blocks backed by a handler in the demos registry in assets/book.js. The handler receives the demo's root element and is bound to any <button data-run> click (plus range/ text input events and radio change events for live demos). This template ships an empty registry — each book adds its own demos. Uncomment and adapt the example handler in book.js to see this demo work.

1.4 Recap

  • Every chapter mirrors this exact structure.
  • Subsection ids (sec-…) are language-neutral anchors for test review links.
  • Diagrams are inline SVG; demos are <div data-demo> backed by a registry in book.js.
  • The test at the bottom uses data-* attributes that book.js scores.
Common pitfalls
  • Don't translate section ids — they're language-neutral.
  • Don't put a literal " inside a data-* JSON array unescaped; wrap the attribute in single quotes and use double quotes inside.
  • Every data-review value MUST match an id="sec-…" in the same chapter.
