# Screenshots

The main README references the images below. Paste your screenshots here with these
exact filenames and they'll show up in the README automatically (no markdown edits
needed).

| File | What to capture | Suggested width |
|---|---|---|
| `hero.png` | Your best shot — the dashboard, or a montage of dashboard + chapter + diagram | ~1760 px (2× display) |
| `dashboard.png` | `en/index.html` — chapter list with mixed statuses (✓ / • / ○) and progress bars | ~1760 px |
| `chapter-diagram.png` | A chapter page scrolled to an inline SVG diagram with its figcaption | ~1760 px |
| `interactive-demo.png` | A demo widget mid-run, showing its output area populated | ~1760 px |
| `test-feedback.png` | Test results with at least one wrong answer highlighted + its "review this section" link | ~1760 px |

Tips:

- Browser full-page screenshots (DevTools → Cmd+Shift+P → "Capture full size screenshot") look best.
- A deliberately "in progress" state (mixed ✓/•/○ statuses, one failed test) demos the
  progress tracking and soft-gate features better than a perfect run.
- Keep the browser window ~880 CSS px wide so the layout matches the README's rendered size.
